# Sistema de Reportes Empresariales

El programa permite generar reportes de información almacenada en una base de datos SQL Server, exportándolos en formatos PDF y Excel.

## Tecnologías utilizadas

- C#
- .NET
- SQL Server
- ADO.NET
- ClosedXML (generación de archivos Excel)
- QuestPDF (generación de archivos PDF)
- Visual Studio

## Funcionalidades

- Conexión a base de datos SQL Server.
- Consulta de información almacenada.
- Generación de reportes en PDF.
- Exportación de información a Excel.
- Opción para generar ambos formatos.
- Menú de opciones desde consola.

## Opciones del sistema

1. Generar reporte PDF.
2. Generar reporte Excel.
3. Generar ambos reportes.
4. Salir del sistema.

## Base de datos

El sistema utiliza SQL Server para consultar la información de la base de datos `UniversidadDB`.

## Objetivo del proyecto

Aplicar conocimientos de programación en C#, conexión a bases de datos y generación de reportes mediante librerías externas.
